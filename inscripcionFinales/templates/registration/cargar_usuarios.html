Carga de docentes

Se puede subir la planilla de la planta docente tal como la tiene la institución:

  • Columnas: Nombre y Apellido, DNI, mail, Carrera, Año y Materia. No hace falta la columna Rol: al subirla, elegí Profesor abajo.
  • Una fila por materia. En las filas siguientes del mismo docente, el nombre (y el DNI y el mail) pueden quedar vacíos.
  • Materia es la materia que dicta: se le asigna como profesor. Un docente nunca queda inscripto como estudiante.
  • Las materias tienen que existir: se buscan por nombre, carrera y año, sin importar acentos ni mayúsculas. Si una materia ya tiene otro profesor, no se cambia.
  • Al terminar, se muestra qué docentes quedaron sin materias y qué materias o carreras no se encontraron. Corregido el archivo, se puede volver a cargar: no duplica nada.

Notas importantes

  • Cada usuario se crea con una contraseña aleatoria distinta, que se muestra una sola vez al terminar la carga (no se vuelve a mostrar). Deberán cambiarla en su primer inicio de sesión.
  • El DNI es el usuario para iniciar sesión: debe ser único y no se puede modificar después. El email, si se completa, también debe ser único.
  • Las carreras deben estar creadas previamente.
  • Si no indicás el Rol, cada usuario se crea con el rol elegido arriba: por defecto, Estudiante.
  • Para estudiantes, se usa el DNI como matrícula por defecto.
  • Si el email o DNI ya existe, no se crea un usuario nuevo, pero igual se le carga la Materia/Nota/Carrera de esa fila si las trae: sirve para cargar notas de alumnos que ya están en el sistema con el mismo archivo.
